# 静思纸页主题设计笔记

日期：2026-07-14
状态：进阶基础版 v0.4
范围：为 TWWE 增加一个受 Claude / Anthropic 编辑式视觉语言启发的原创主题，不复制商标、品牌插画或专有字体。

## 目标

“静思纸页”不是给现有深色玻璃主题换一组颜色，而是建立一套安静、温暖、书卷化的浅色界面基础：

- 用纸张层级替代透明玻璃和霓虹光晕。
- 用字体、留白和明度层级表达信息结构。
- 保持游戏工具所需的信息密度、状态颜色和可访问性。
- 先覆盖全局基础，再逐步为高价值组件增加专属设计。

## 调研依据

### 一手来源

- [Claude 产品页](https://claude.com/product/overview)：当前站点实际使用 `Anthropic Sans`、`Anthropic Serif`、`Anthropic Mono`，并暴露暖灰、象牙白和陶土色设计变量。
- [Geist / Anthropic 品牌案例](https://geist.co/work/anthropic)：包含实际配色板、字体、Claude 页面、摄影和品牌规范展示。
- [Everett / Anthropic 项目复盘](https://byeverett.com/anthropic)：将创意原则概括为“温暖胜过现代感、可接近胜过排他、克制胜过炫技”。

### 专业分析

- [D1S1：The Two Schools of AI Branding](https://d1s1.com/blog/ai-branding-invisible-vs-magical)：把 Anthropic 描述为“warm, bookish, deliberately analog”，即温暖、书卷化、刻意保留模拟媒介感。

## 基础设计令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Canvas | `#E8E6DC` | 应用工作区背景，拉开工作台与纸面的明度差 |
| Surface | `#F5F4ED` | 主面板、页眉、页脚 |
| Raised | `#FAF9F5` | 属性框、输入框和抬升纸面 |
| Border Soft | `#E8E6DC` | 默认细分隔线 |
| Border | `#D1CFC5` | 输入框、明确边界 |
| Ink | `#141413` | 主文字 |
| Ink Secondary | `#30302E` | 次级标题、按钮文字 |
| Ink Muted | `#5E5D59` | 辅助说明 |
| Accent | `#C96442` | 主要操作、选中状态 |
| Accent Soft | `#F1DFD6` | 强调背景 |
| Spell Filled | `#5E5D59` | 已放置法术的暖石墨标本卡 |

`#D97757` / `#C96442` 在暖白背景上不适合直接承担小号正文，因此主题使用更深的 `#93412C` 作为强调文字色。

## 字体策略

Claude 的字体为专有字体，本项目不直接复制。基础版采用本地字体栈：

- UI：`Inter`、`Noto Sans SC`、微软雅黑、苹方等无衬线字体。
- 标题：`Iowan Old Style`、`Palatino Linotype`、`Noto Serif SC`、宋体等编辑式衬线字体。

基础版只对语义标题应用衬线体，并把原界面大量 `font-black` 降到 `600`，避免浅色界面显得拥挤粗重。

## 基础版覆盖范围

- 主题选择和中英文名称。
- 固定暖白背景；选择该主题时忽略动态极光、矩阵和霓虹背景。
- 应用背景、页眉、页脚、面板、玻璃卡片、输入框和常见按钮。
- 主文字、辅助文字、品牌色和基础语义状态色。
- 暖灰边框、轻量悬停、键盘焦点和减少动态偏好。
- DOM 法术格与 Canvas 2D 法术格的浅色基础调色。

## v0.2 层级修正

实际使用中，`#FAF9F5` 同时承担背景、面板和法术格会让编辑区缺少层次，而且浅色法术图标会消失在纸面上。v0.2 调整为：

- 工作区使用更深的暖纸色 `#EDE9DF`，面板和属性框逐级变亮。
- 空法术槽继续使用浅色纸面，保持编辑器轻盈。
- 已放置法术使用暖石墨标本卡，确保白色和浅色像素图标具有稳定对比。
- 法杖标题栏中的法术预览缩略图同步使用深色承托，避免展开前后出现两套可读性标准。
- 未知法术使用深棕色卡片，在保持统一材质的同时保留警告语义。
- DOM 与 Canvas 2D 渲染采用相同的“空槽浅、实槽深”规则。

## v0.3 法术图标承托层

截图复核发现，法术图标不仅出现在编辑器，还分散在法杖摘要、法术仓库、选择器、历史记录、设置页与评估器执行流中。逐组件编写主题 CSS 会继续产生遗漏，因此 v0.3 增加统一语义类 `spell-icon-surface`：

- 所有 DOM 法术图标只声明同一个语义类，不再携带静思纸页专属底色。
- 主题集中提供暖石墨承托，白色像素图标在所有入口都保持稳定对比。
- 标记、禁用、灰度和悬停仍由组件原有状态样式负责，承托层不覆盖这些交互语义。
- 工作台改为更中性的 `#E8E6DC`，主纸面改为 `#F5F4ED`，抬升纸面保留 `#FAF9F5`，避免整页米白明度过于平均。
- 非 DOM 渲染器无法使用 CSS 语义类；当前实际调用的 Canvas 2D 树直接读取同一组 CSS 色彩令牌，避免再次复制色值。

## v0.4 时间轴与执行树

第二轮截图暴露了基础工具类映射无法覆盖任意透明度类的问题：时间轴的 `bg-zinc-950/45` 与 `bg-white/[0.03]` 混入旧深色材质，执行树则形成浅色节点外壳包裹深色图标的“双层卡片”。v0.4 调整为：

- 时间轴拥有独立语义结构，工具栏、事件元数据、演算区与牌堆分别落在 Raised、Surface 与 Recessed 纸面层级。
- 时间轴滑轨改为细暖灰轨道与陶土色滑块，不再依赖浏览器默认深色控件外观。
- 执行树主体使用低对比暖灰工作区；Cast 节点使用陶土浅洗，法术节点直接使用单层暖石墨卡。
- 法术承托由近黑改为 Claude 灰阶中的 `#5E5D59`，描边和阴影同步减弱，避免在浅色页面上呈现黑色贴纸感。
- 移除法术格对图片 `filter` 的强制覆盖，保留耗尽法术原有的灰度状态。

## 暂不包含

这些内容留给后续“完成度优化”，每次围绕一个组件验证：

1. Header 品牌区、标签栏和同步状态的专属排版。
2. WandCard、属性表、法术槽和评估树的编辑式组件语言。
3. 设置页主题选择器自身的视觉重构。
4. 仓库、法术选择器、悬浮 Dock 和 Canvas 节点的进一步排版层级。
5. 原创手绘装饰、纸张纹理或低频微动效。
6. 深色“夜间纸页”变体。

后续优化应继续遵守：少量准确的专属规则优先于堆叠全局 `!important` 覆盖。
